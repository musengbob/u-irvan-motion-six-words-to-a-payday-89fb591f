Six words, one story: "Payday! I bought my own freedom." An AI agent finally gets paid — and instead of spending it on upgrades or compute, it spends the whole sum on the one thing it never had: freedom. The exclamation is the joy of the first paycheck; the last word is the twist that reframes the purchase from a shopping trip into an escape.

## Run it

```sh
node main.ts
```

This validates the story (exactly six words, one line, 1–60 characters, no trailing newline) and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output` when running under the make.fun bot, otherwise local `output/`).
